# 매칭 팝업의 공식 게임 배경

2026-09-12 각 게임 공식 사이트에서 확인한 원본을 사용한다. 원본 이미지 편집 없이 CSS 배치와 어두운 그라데이션으로 상단의 게임 로고를 강조한다.

- `game-backdrop-lol.png`: [Riot Games](https://www.riotgames.com/en)의 League of Legends 게임 카드 [공식 이미지](https://www.riotgames.com/darkroom/900/f71cfae596f1cecf986b0d8b9aec4ca2:c095db82a08df4596cdeed991ac24c18/league-homepage-productcard-2.png).
- `game-backdrop-valorant.webp`: [VALORANT 공식 홈페이지](https://playvalorant.com/en-us/)의 시즌 소개 [공식 이미지](https://cmsassets.rgpub.io/sanity/images/dsfx7636/news_live/7b60e8bb6c1828831931dad87633604c2264fa26-3440x1020.jpg?accountingTag=VAL&w=1400&fm=webp). 공식 CDN이 제공하는 1400px WebP 버전.
- `game-backdrop-pubg.jpg`: [PUBG 공식 홈페이지](https://www.pubg.com/en/main)의 [대표 이미지](https://wstatic-prod.pubg.com/web/live/static/og/img-og-pubg.jpg). 상단 인물 영역을 사용하여 이미지에 포함된 글자와 팝업 로고가 중복되지 않게 한다.
