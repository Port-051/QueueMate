## 발견 → 수정 → 재검증

1. 로그인 리다이렉트를 따라간 최종 200을 랜딩 응답으로 오인할 수 있었습니다. GET 검사에서 리다이렉트를 따라가지 않도록 고정하고, Vercel 로그인 이동과 401/403을 `BLOCKED_AUTH`로 구분했습니다.
2. 이미지 MIME만 확인하면 잘못된 파일도 정상으로 보일 수 있었습니다. WebP 컨테이너 길이·해상도, SVG 본문, HTML로 위장된 이미지, 손상 파일에 대한 검증을 추가했습니다.
3. 원격 브라우저 첫 접속에서 `/favicon.ico` 404가 발견됐습니다. 기존 워드마크의 Q를 이용한 아이콘과 무결성 테스트를 추가했습니다. 이후 브라우저 92개가 통과하고 Lighthouse 권장사항은 96에서 100으로 바뀌었습니다. 전후 측정의 글꼴 환경도 달라졌으므로 성능 수치의 인과효과까지 주장하지 않습니다.
4. 실행 서버의 한글 글꼴 누락으로 초기 스크린샷 글자가 깨졌습니다. 검사 서버에 한글 글꼴을 설치하고 모든 화면·접근성·Lighthouse 검사를 다시 실행했습니다. 글꼴 파일 자체는 결과물에 배포하지 않습니다.
