# QueueMate 에셋 작업 폴더

이미지 생성은 **Codex(외부 도구)** 가 맡고, 규격 맞추기(크롭·리사이즈·WebP 변환)는
`postprocess.py`가 맡는다.

## 폴더

```
queuemate-assets/
├── README.md          이 파일 — 워크플로와 팔레트
├── PROMPTS.md         Codex에 그대로 붙여넣을 프롬프트 12장분
├── postprocess.py     생성 원본 → 최종 규격 자동 변환
├── raw/               Codex가 뽑은 원본을 여기 넣는다
└── final/             postprocess.py 결과. 이것만 frontend/public/으로 간다
```

## 작업 순서

1. `PROMPTS.md`에서 항목 하나를 골라 프롬프트를 Codex에 붙여넣는다
2. 나온 이미지를 **지정된 파일명 그대로** `raw/`에 저장한다 (파일명이 틀리면 3번이 못 찾는다)
3. `python3 postprocess.py` 실행 → `final/`에 규격에 맞는 파일이 생성된다
4. `final/` 결과를 눈으로 확인한다. 마음에 안 들면 1번으로 돌아가 재생성

전체를 한 번에 다 뽑을 필요는 없다. **P1 12장(GEN-1, 3, 4)부터** 하면 화면이 눈에 띄게 채워진다.

## 팔레트 — 프롬프트에 이 값만 쓴다

목업 13장에서 픽셀로 실측한 값이다. 이 밖의 색(청록, 노랑, 분홍 등)이 나오면 재생성한다.

| 역할 | HEX | 비고 |
|---|---|---|
| 배경 | `#020715` | 화면의 65~70%를 차지하는 지배색 |
| 패널 | `#070E1D` | |
| 카드 | `#141A2C` | |
| **보라 액센트** | `#7E2DF2` | **화면 면적의 10%를 넘기지 않는다** |
| 밝은 보라 | `#9A56FF` | 하이라이트/글로우 |
| 초록 | `#24C254` | 온라인 상태 |
| 빨강 | `#EF4347` | 위험/취소 |
| 주황 | `#F6660E` | 경고 |
| 밝은 텍스트 | `#E8E9F2` | 발광 요소에도 사용 |

**보라를 아끼는 것이 이 디자인의 핵심이다.** 목업 실측 결과 보라는 화면의 10% 미만이고
나머지는 전부 어두운 남색이다. 보라가 넓게 깔린 결과물은 QueueMate처럼 보이지 않는다.

## 모든 이미지에 공통으로 적용되는 금지 사항

프롬프트마다 반복해 넣어 뒀지만, 결과를 검수할 때도 이 기준으로 본다.

- **글자·문자·숫자·기호가 일절 없을 것.** 간판, 표지판, HUD, 워터마크, 서명, UI 요소, 달력 숫자 전부 포함
- 실존 게임(League of Legends / VALORANT / PUBG)의 로고·캐릭터·요원·챔피언·아이템을 연상시키는 요소 금지 — 상표·저작권 문제다
- 실사 인물 얼굴 금지
- 과금·프리미엄·랭크 티어·별점·레벨 게이지를 연상시키는 장식 금지
- 상대팀·대전·VS 구도 금지 (QueueMate는 같은 편만 만든다)

## 후처리에 필요한 것

`postprocess.py`는 Python 3 + Pillow만 쓴다. 이미 설치돼 있다.

```bash
python3 -c "import PIL; print(PIL.__version__)"   # 확인
python3 postprocess.py                            # 전체 처리
python3 postprocess.py --only avatar              # 특정 항목만
```
