# 생성 결과 검수

PROMPTS.md 코드블록 원문을 내장 image_gen 도구에 전달했다. GEN-4는 [VARIANT], GEN-5는 [SCENE]만 문서 표의 문장으로 교체했다. GEN-5와 GEN-6은 raw/gen1-mascot-banner.png를 참조했다.

raw/의 문서 지정 파일명 17개를 확인했다. 원본 픽셀은 수정하지 않았다. 실제 크기와 알파 채널 정보는 asset-validation.json에 기록했다. 일부 원본은 도구가 문서의 생성 크기와 다르게 반환했다.

- GEN-1: 기존 임시 선정본. 눈 크기가 달라 좌우 대칭 기준 미통과.
- GEN-3: 세 장 모두 어두운 배경이며 좌측 여백과 무인 구도를 확보했다. PUBG는 추가 후보보다 첫 후보가 어두워 첫 후보를 저장했다. 나란히 비교했을 때 PUBG의 하늘은 다른 두 장보다 밝다. 완전한 톤 일치로 판정하지 않았다.
- GEN-4: 8장 모두 실제 RGBA 투명 배경. gen4-review-64px.png에서 64px 축소 구분을 확인했다. 전체 화풍은 유사하지만 원문보다 눈과 머리카락이 세밀하다. 6번에는 원문에 없는 후드가 추가됐다. 생성 원본 크기는 1024×1024가 아니다.
- GEN-5: GEN-1의 후드·고양이 귀·그림자 얼굴·발광 눈 조형을 유지한다. match와 social은 실제 알파 채널이 있다. match는 색이 다소 선명하며 social에는 넓은 반투명 광채가 있다. reservation은 세 번 생성했으나 체크무늬가 픽셀로 구워진 RGB 결과가 반복됐다. 저장본은 첫 후보이며 투명 배경 기준 미통과다.
- GEN-2: 큰 대각선 흐름은 읽히고 물체는 없다. 보라색 광채 면적은 원문의 제한보다 넓게 보인다.
- GEN-6: 마스코트 조형은 유지되지만 입자와 손이 좌측 55% 영역에 일부 들어와 여백 기준 미통과다.

모든 검수를 통과한 배포본으로 간주하면 안 된다. postprocess.py는 실행하지 않았다. 변환만으로 위 시각적 불일치나 가짜 투명 배경이 해결되지 않는다.
