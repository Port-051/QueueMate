## 정책과 범위

자동 마감은 두 명 이상이고 정원 미달인 실시간 방에 적용한다. 멤버 변경 후 10분, 안내 60초는 멘토가 지정한 값이 아닌 시제품 시험값이다. 예약 방과 기존 기한 없는 저장 데이터에는 소급 적용하지 않는다. 오래된 타이머가 연장된 방을 닫지 않도록 기한과 소유자를 재검증한다. 기한이 지난 방은 빠른 연결 및 입장에서 재검증한다.

현재 `dev:mock` 전용 프론트엔드 시제품이며 브라우저 저장소를 사용한다. 실제 백엔드 경로와 API 계약은 변경하지 않았다. 호스트 화면이 열린 동안 자동 마감을 처리하고 닫혔다면 재진입 시 처리한다. 서버가 항상 실행하는 만료 작업은 후속 구현이다.

음성 버튼은 기존 MockPartyClient의 상태 UI다. 실제 WebRTC 오디오·상대방 발화 감지·다중 사용자 동기화는 아직 연결하지 않았다. 초록 테두리는 내 마이크 준비 상태이며 발화 감지로 표현하지 않는다. 음성 기록을 새로 저장하거나 보여주지 않는다.

빠른 연결은 같은 방 풀을 사용하며 목록을 먼저 볼 수 있도록 접을 수 있는 상단 진입점으로 변경했다. 문서 23의 이전 기본 필터 설명은 이 문서로 대체한다: 모집 마감된 방도 기본 표시한다.

광고 집행·외부 배포·검색 엔진 등록은 이번 UI 작업에 포함하지 않았다.

## 사용자 교정: 고정 사이드바와 균일한 카드

사용자 최신 지시에 따라 접이식 빠른 연결을 제거했다. 데스크톱 오른쪽 고정 패널은 항상 존재하며 빠른 연결, 방 생성, 참여한 방 대화 상태를 같은 위치에서 표시한다. 작은 화면에서는 패널을 접지 않고 목록 위에 배치한다. 예약 목록을 볼 때에도 빠른 연결은 '지금 플레이'로 명확히 표시한다.

목록은 246px 높이의 단일 열 방 카드로 통일했다. 멤버 정보는 정원에 맞춘 가로 슬롯으로 표시하며 빈 슬롯은 모집 중인 자리로 사용한다. 카드 겹침 장식 및 상세 펼침 애니메이션을 제거했다. 실제 내장 브라우저에서 카드 9개 동일 높이, 가로 넘침 없음, 사이드바 조건 선택과 추천 결과를 확인했다.

### 메인 브랜치 시각 기준 재적용

`main`의 `HomePage.tsx`, `HomeProfileRail.tsx`, `duo-home.css`를 확인했다. 얇은 목록 구분선, 내 프로필이 있는 오른쪽 패널, 14–16px 중심의 정보 계층을 참고했다. 개인 카드와 빈 슬롯은 인원수와 무관하게 140×150px로 고정한다. 닉네임/승률/KDA는 14px, 티어는 13px, 방 제목은 17px로 확대했다. 좁은 화면에서는 개인 카드 줄 내부에서 가로 스크롤해 글자를 축소하지 않는다. 기존 오른쪽 패널 상시 표시와 방별 동일 높이는 유지한다.

### 사이드바를 메인 컴포넌트로 교체

앞선 스타일 참조에서 `matching-rail.css`의 패널 스타일과 실제 입력 폼 구조를 빠뜨린 점을 수정했다. `main` (`f860ada`)과 변경 없는 `HomeProfileRail`, `SelfIntroductionFields`, `matching-rail.css`를 직접 재사용한다. 프로필/게임 계정 → 게임 모드 버튼 → 복수 포지션 → 찾는 포지션 → 음성 버튼 → 한마디 → 매칭 시작 순서를 유지한다. 별도 빠른 연결 제목과 게임 모드/마이크 드롭다운을 제거했다.

메인의 입력 폼은 공유하되 시작 동작은 방 시제품의 같은 후보 풀을 사용한다. 복수 포지션은 방의 모집 포지션 중 하나와 일치해야 하며 찾는 포지션은 현재 멤버 역할 중 하나와 일치해야 한다. 한마디는 추천 조건이 아닌 입장 프로필로 전달한다. 목록 필터와 내 매칭 조건은 독립적으로 유지하고, 방 확인 후 입장할 때 추천 시점 조건을 다시 검증한다. 프로토타입 범위와 서버 미연결 상태는 그대로다.

검증: 프론트 빌드, 순수 테스트 15개, 크롬에서 서포터/미드 조건 선택 → 추천 → 해당 방 상세 진입 확인.

### 매칭 추천 박스 위치

추천 결과를 입력 폼 내부에서 제거하고 `HomeProfileRail.below`에 전달한다. 메인과 동일하게 프로필·조건 패널 아래에 `duo-offers` / `duo-offer` 스타일의 독립 박스를 표시한다. 조건 변경 시 추천을 지우는 동작과 방 확인 흐름은 유지한다.

### 멤버 정보 구분과 두 상태 마이크

방 목록의 요약을 모드·방 제목·모집 상태/인원·찾는 포지션·마이크 아이콘 한 줄로 통합했다. ‘멤버 자세히 보기’와 별도 하단 설명은 제거했다. 프로필 사진을 복원하고 개인 카드/빈 슬롯을 140×196px로 통일했다. 개인 포지션은 아이콘과 이름을 강조한 독립 줄, 챔피언은 구분선 아래 독립 줄로 배치한다.

방·멤버의 마이크는 사용(초록 마이크)/미사용(빨강 음소거) 두 아이콘으로 표시한다. 툴팁과 접근성 이름은 유지한다. 목록 필터, 방 생성, 메인에서 재사용하는 입력 폼의 방 화면 옵션에도 두 상태를 적용한다. 기존 OPTIONAL 저장 데이터는 사용자 선택 전 미사용으로 정규화하며 신규 방에는 OPTIONAL을 허용하지 않는다. API 공통 enum과 다른 화면은 변경하지 않았다.

검증: 빌드 및 순수 테스트 15개 통과. 크롬에서 프로필 이미지 21개 표시, 카드 크기 동일/세로 잘림 없음, 안내 문구 제거, 사용 아이콘 필터 적용 시 사용 방만 표시, 방 생성 마이크 버튼 두 개와 화면 텍스트 없음 확인.
