# 게임별 파티·매칭 참가 조건 조사

확인일: 2026-09-26. 공식 게임사 패치 노트·지원 문서만 근거로 사용했다.
기준은 한국 PC 이용자와 현재 QueueMate가 제공하는 모드다. 자유랭크는 다인 방에 직접 관련되어 함께 조사했다. 격전·Premier는 확장 시 참고 사항이다. 기간 한정 이벤트, 사용자 지정 경기, 모바일 게임의 규칙까지 포괄하는 문서는 아니다.

**이 문서는 조사 결과와 구현 제안이다. 아래 제안을 모두 구현한 상태는 아니다.** 이번 UI 변경은 방 상단의 `모집 중`을 빈자리 카드 안으로 옮기는 것이다.

## 1. 먼저 구분할 것

- **게임 참가 제한:** 함께 게임 큐를 돌릴 수 있는 인원·랭크·계정 자격. 방장 동의로 우회할 수 없다.
- **방의 선호 조건:** 특정 포지션, 챔피언, 승률, KDA, 마이크, 플레이 목적. QueueMate에서 서로 합의하는 조건이다.
- **모집 목표 인원:** 모으려는 인원과 지금 들어온 인원은 다르다. 5인 방의 현재 인원이 4명인 상태는 정상적인 모집 과정이다.
- **게임 내 실제 출발 인원:** 확정 또는 게임 시작 시점에 다시 검사한다. 지원하지 않는 4인 큐를 5인 방의 임시 상태와 혼동하면 안 된다.

평균 티어는 방을 설명하는 정보로만 사용한다. 참가 가능 여부는 **입장 후보를 포함한 전체 구성원**으로 판단해야 한다. 빈자리에 사람이 들어오거나 나간 뒤, 모드를 바꾼 뒤에도 다시 판단해야 한다.

## 2. 리그 오브 레전드

### 모드와 인원

아래 인원은 완성된 게임 팀의 5명이 아니라, 함께 큐를 돌리는 사전 구성 파티의 인원이다.

| 모드 | 사전 구성 인원 | 표시 티어 차이 | 참가 자격 및 특성 |
| --- | --- | --- | --- |
| 개인/2인 랭크 | 1·2명 | 제한 있음 | 한국 마스터 이상 듀오 불가 |
| 자유랭크 | 1·2·3·5명 | 다이아 이하 제한 없음. 마스터 이상 포함 시 전원 에메랄드 이상 | 4명 불가. 개인/2인 랭크와 별도 랭크 |
| 일반 교차 선택 | 1~5명 | 확인한 공식 문서에 랭크 격차 제한 없음 | 10레벨부터. 챔피언 선택·금지 및 포지션 배정 존재 |
| 신속 대전 | 1~5명 | 확인한 공식 문서에 랭크 격차 제한 없음 | 3레벨부터. 입장 전 챔피언·포지션 선택 |
| 무작위 총력전(칼바람) | 1~5명 | 확인한 공식 문서에 랭크 격차 제한 없음 | 3레벨부터. 무작위 챔피언, 협곡의 5포지션 배정 없음 |

랭크 인원·격차는 [라이엇 랭크 안내](https://support.riotgames.com/ko-kr/league-of-legends/gameplay/ranked-tiers-divisions-and-queues), 한국 상위 티어 예외는 [26.15 한국어 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-15-notes/) 기준이다. 일반 모드의 다인 플레이는 [공식 2~5인 사전 구성 이벤트 안내](https://www.leagueoflegends.com/ko-kr/news/notices/2025-lol-winter-event/), 신속 대전 인원별 규칙은 [신속 대전 안내](https://support.riotgames.com/en-us/league-of-legends/gameplay/swiftplay-game-mode)를 함께 확인했다. 이벤트의 기간·보상은 현재 규칙으로 사용하지 않았다.

랭크 진입에는 **30레벨, 챔피언 최소 20개, 신속 대전 또는 일반 교차 선택 10경기**가 필요하다. 일반 교차 선택의 별도 챔피언 풀 최소 개수·무료 로테이션 포함 여부는 이번에 확인한 최신 잠금 해제 문서에 명시되지 않아 확정하지 않았다. [모드 잠금 해제 안내, 2026-05-29](https://support.riotgames.com/en-us/league-of-legends/gameplay/unlocking-game-modes)

### 개인/2인 랭크의 티어 범위

| 본인 티어 | 공식 안내 범위 |
| --- | --- |
| 아이언 | 아이언~실버 |
| 브론즈 | 아이언~실버 |
| 실버 | 아이언~골드 |
| 골드 | 실버~플래티넘 |
| 플래티넘 | 골드~에메랄드 |
| 에메랄드·다이아몬드 | 다이아 상대는 세부 단계까지 판단 필요. 아래 불일치 참고 |
| 마스터·그랜드마스터·챌린저 | 한국 개인/2인 랭크에서는 듀오 불가 |

예: 실버+골드는 가능 범위, 브론즈+골드는 불가 범위다. 다만 표시 티어만 통과했다고 실제 큐 진입을 보장하지는 못한다. [랭크 안내](https://support.riotgames.com/ko-kr/league-of-legends/gameplay/ranked-tiers-divisions-and-queues)

**공식 문서 자체의 불일치:** 같은 지원 문서의 표는 `다이아 IV~II → 에메랄드 II~다이아 II`를 한 행에 묶고, 본문은 다이아에 대해 `2단계 이내`라고 설명한다. 에메랄드 행의 넓은 범위와 상대방 행도 일관되게 대응하지 않는다. 따라서 이 표를 그대로 양방향 허용 행렬로 옮기지 않는다. 다이아 세부 경계는 게임 클라이언트 또는 라이엇 답변으로 추가 검증할 항목이다. [해당 표와 본문](https://support.riotgames.com/ko-kr/league-of-legends/gameplay/ranked-tiers-divisions-and-queues)

한국의 마스터 이상 금지는 2026-07-28 발표된 **26.15 패치에서도 명시적으로 유지**됐다. 해외의 마스터 듀오 허용을 한국에 적용하면 안 된다. [26.15 한국어 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-15-notes/)

표시 티어 외에 상위 MMR 제한도 있다. 26.1의 시즌 초 임시 완화는 26.2부터 되돌아갔다. MMR은 공개되지 않으므로 QueueMate가 표시 티어만 보고 `게임 시작 가능 확정`이라고 안내하면 부정확하다. [26.2 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/patch-26-2-notes/), [MMR 안내](https://support.riotgames.com/en-us/league-of-legends/gameplay/mmr-rank-and-lp)

### 포지션과 챔피언

| 모드 | 공식 규칙 | QueueMate에 적용할 해석 |
| --- | --- | --- |
| 신속 대전 1인 | 서로 다른 챔피언 2개·포지션 2개, 그중 우선 포지션 최소 1개 | 선호 챔피언 3개를 표시하는 것과 실제 사전 선택은 다름 |
| 신속 대전 2~4인 | 각자 1인 규칙 충족. 파티 내 각자 사용 가능한 고유 챔피언 최소 1개. 주 선택의 챔피언과 포지션 중복 불가 | 희망 포지션만 맞춰도 실제 클라이언트 선택에서 충돌할 수 있음 |
| 신속 대전 5인 | 각자 서로 다른 챔피언 1개 | 공식 FAQ의 5인 항목은 챔피언 고유성만 명시함 |

우선 포지션은 서버 수요에 따라 바뀐다. 정글·서포터로 고정하면 안 된다. 위 규칙은 [신속 대전 공식 FAQ](https://support.riotgames.com/en-us/league-of-legends/gameplay/swiftplay-game-mode) 기준이다.

일반 교차 선택·랭크의 희망 포지션은 배정 결과를 완전히 보장하지 않으며 자동 선택이 발생할 수 있다. [대전 검색과 자동 선택](https://support.riotgames.com/en-us/league-of-legends/gameplay/matchmaking-and-autofill)

칼바람은 무작위 챔피언 모드다. 따라서 `서포터 자리가 반드시 남아야 참가 가능`, `특정 챔피언 플레이 보장`을 게임의 필수 규칙처럼 적용하면 안 된다. [칼바람 공식 FAQ](https://support.riotgames.com/en-us/league-of-legends/gameplay/aram-game-mode)

현재 QueueMate의 **5인 협곡 방에서 본인 1포지션+상대 4포지션을 지정하게 하는 규칙**은 사용자가 요청한 팀 구성 정책이다. 게임사의 모든 모드에 공통 적용되는 방 생성 조건으로 설명하지 않는다.

### 격전 — 향후 별도 지원 시

5명, 30레벨, SMS 인증, 각자 티켓과 정해진 참가 시간이 필요하다. 협곡 격전은 올해 또는 전년도 협곡 랭크 배치 완료가 요구되며, 칼바람·무작위 URF 격전은 랭크 참가 이력이 면제된다. 실력 차이는 팀 티어 산정에 반영된다. 실시간 일반 방과 같은 규칙으로 취급하지 않는다. [격전 FAQ, 2026-05-07](https://support.riotgames.com/ko-kr/league-of-legends/events/clash-faq)

## 3. 발로란트

### 경쟁전

| 항목 | 공식 규칙 |
| --- | --- |
| 계정 | 20레벨 이상. 에피소드 4 이전 경쟁전 참가 계정 예외 |
| 인원 | 1·2·3·5명. **4명 불가** |
| 불멸 1 이상 포함 | 1·2·5명만 가능. 3명 불가 |
| 2·3인, 최저 아이언/브론즈 | 최고 실버 |
| 2·3인, 최저 실버 | 최고 골드 |
| 2·3인, 최저 골드 | 최고 플래티넘 |
| 2·3인, 최저 플래티넘 이상 | 최대 한 티어 위의 같은 단계까지. 예: 플래티넘 2↔다이아몬드 2 |
| 5인 | 티어 격차 제한 없음. 아래 RR 감점 조건 적용 |

5인 RR 감소는 전원 초월자 3 이하이면서 일반 격차를 넘으면 25%, 불멸 포함 시 25%, 레디언트 포함 시 75%, 레디언트와 하위 랭크가 섞이면 90%다. 5인은 다른 5인 파티와 연결되므로 대기가 길어질 수 있다. `참가 불가`와 `참가 가능하지만 RR 감소`를 구분한다. [경쟁전 공식 FAQ, 2026-05-17](https://support.riotgames.com/en-us/valorant/gameplay/valorant-competitive-mode-faq)

### 일반전과 플랫폼

일반전은 1~5인 파티 대상으로 설계할 수 있고, 경쟁전의 티어 격차 제한을 가져오면 안 된다. 라이엇은 일반전에서 친구 간 실력 차이를 이유로 파티를 제한하지 않는다고 설명한다. 다인 파티 안내에는 2·3·4·5인이 명시돼 있다. [일반전 매치메이킹 설명](https://playvalorant.com/en-gb/news/dev/ask-valorant-1/), [공식 다인 파티 안내](https://playvalorant.com/en-gb/news/game-updates/valorant-2022-year-end/)

PC와 콘솔은 함께 매칭되지 않으며 랭크·MMR도 별개다. 콘솔끼리 Xbox/PlayStation 교차 플레이는 지원한다. [콘솔 공식 안내, 2026-06-02](https://support.riotgames.com/en-us/valorant/gameplay/valorant-console-guide)

타격대·척후대·전략가·감시자는 요원의 역할 분류다. 확인한 경쟁전 참가 규칙에는 네 역할을 반드시 한 명씩 채우라는 조건이 없다. QueueMate에서는 조합 선호로 다루고, 롤의 5포지션 분배를 그대로 적용하지 않는다.

### Premier와 향후 모드

Premier는 5~7명 로스터, 첫 경기 이후 디비전에 영향을 주는 영입 제한, 지정 지역·일정 등 별도 팀 규칙이 있다. SMS 인증, 계정 내 최소 1회 랭크 배치 완료, 제재 없는 상태를 요구한다. 제재 기간 문구는 2025 팀 생성 안내와 2026 참가 안내가 달라 최신 참가 안내와 클라이언트 확인을 우선한다. [팀 생성](https://support.riotgames.com/en-us/valorant/gameplay/premier-team-creation-management), [참가 자격, 2026-03-30](https://support.riotgames.com/en-us/valorant/gameplay/premier-joining-leaving-teams)

13.06 패치에 언급된 `Competitive Flex`는 **14.00 예정 기능**이다. 현재 제공되는 모드로 구현하지 않는다. [13.06 패치](https://playvalorant.com/en-gb/news/game-updates/valorant-patch-notes-13-06/)

## 4. PUBG: 배틀그라운드

`듀오/스쿼드`는 인원 형식이고 `일반/경쟁전`은 서로 다른 축이다. 현재 QueueMate의 `DUO`, `SQUAD`만으로는 경쟁전 제한을 정확히 판정할 수 없다.

| 구분 | 팀 정원 | 함께 큐를 돌리는 인원 | 티어 격차 |
| --- | --- | --- | --- |
| 일반 듀오 | 2명 | 최대 2명 | 확인한 공식 안내에 경쟁전식 격차 제한 없음 |
| 일반 스쿼드 | 4명 | 최대 4명. 3인도 스쿼드 | 확인한 공식 안내에 경쟁전식 격차 제한 없음 |
| 경쟁전 듀오 | 2명 | 최대 2명 | 사전 구성 파티 최대 12단계 차이 |
| 경쟁전 스쿼드 | 4명 | 최대 4명 | 사전 구성 파티 최대 12단계 차이 |

솔로는 한 명이므로 QueueMate의 함께할 사람 모집 대상에서 제외하는 편이 자연스럽다. 듀오·스쿼드의 팀 정원은 [공식 플레이 안내](https://support.pubg.com/hc/en-us/articles/115004198834-How-to-play-PUBG), 경쟁전 듀오는 [36.1 패치](https://www.pubg.com/ko/news/8725), 격차는 [38.1 패치](https://www.pubg.com/ko/news/9273) 기준이다. 일반전도 내부 MMR로 실력을 고려하며, 티어 격차 제한이 없다는 것과 무작위 대전은 다른 뜻이다. [일반전 매치메이킹 개발일지](https://pubg.com/en/news/7174)

### 경쟁전 자격과 최신 티어 체계

- 글로벌 플러스 안내: 경쟁전 이용 권한과 **생존 마스터리 80레벨** 필요. 카카오의 이용권·PC방 예외까지 이 페이지로 단정하지 않는다. [공식 플러스 안내](https://pubg.com/ko/game-info/pubg-plus)
- 플랫폼·지역에 따라 SMS 인증 필요. 탈주 등으로 큐 대기 제재가 있으면 진입이 제한된다. [경쟁전 FAQ](https://support.pubg.com/hc/en-us/articles/360048004774-Frequently-Asked-Questions-about-Ranked-Mode)
- 2025-10-14의 38.1 패치는 파티 제한을 **10→12단계**로 확대했다. 같은 FAQ의 10단계 문구는 이전 규칙이다. [38.1 변경 사항](https://www.pubg.com/ko/news/9273)
- 36.1부터 크리스탈·서바이버가 추가되고 하위 디비전은 5→4단계가 됐다. 순서는 브론즈→실버→골드→플래티넘→크리스탈→다이아몬드→마스터→서바이버다. 듀오/스쿼드·시점별 경쟁전 RP도 통합됐다. [36.1 개편](https://www.pubg.com/ko/news/8725), [38.1 티어 목록](https://www.pubg.com/ko/news/9273)

12단계는 `12개 대분류 티어`라는 뜻이 아니다. 일반 디비전 구간의 계산 예로 브론즈 IV→플래티넘 IV는 12단계다. 마스터·서바이버 경계와 배치 중 계정까지 단순 등차 계산으로 허용하지 말고 별도 검증한다. 오래된 FAQ의 배치 예외도 최신 개편 이후 동작을 확인하기 전까지 무조건 허용 근거로 사용하지 않는다.

### 지역·플랫폼·시점

- PC Steam↔Epic은 교차 플레이, 콘솔 Xbox↔PlayStation은 교차 플레이다. PC/콘솔을 같은 풀로 합치지 않는다. [매치메이킹 개발일지](https://pubg.com/en/news/7174)
- 카카오와 Steam의 분리 운영은 [카카오 공식 공지](https://bbs.pubg.game.daum.net/gaia/do/pubg/update/read?articleId=61&bbsId=PN001)로 확인되지만 오래된 자료다. 현재도 구분 필드를 유지하고, 통합 가능하다고 판단할 새 근거 없이 같은 방으로 추천하지 않는 것이 설계상 안전하다.
- FPP와 TPP는 다른 매칭 설정이다. TPP 경기 중 1인칭으로 전환할 수 있다는 사실이 FPP 큐와의 호환을 의미하지 않는다. [공식 플레이 안내](https://support.pubg.com/hc/en-us/articles/115004198834-How-to-play-PUBG)
- 36.1에서 경쟁전 듀오가 추가됐지만 지역·시점 예외가 있다. 40.1에서도 RU/NA/SA 큐 구성이 바뀌었다. 게임사가 인구와 매칭 상황에 따라 제공 조합을 바꿀 수 있다고 명시하므로, 2025년 지역 표를 영구 규칙으로 사용하지 않는다. [36.1](https://www.pubg.com/ko/news/8725), [40.1](https://www.pubg.com/en/news/9690)

공격적·균형·생존 중심이라는 현재 서비스의 플레이 스타일은 게임사의 필수 역할 배분이 아니다. 빈자리 한 칸에 여러 허용 스타일을 표시할 수 있다.

## 5. 현재 코드와 비교한 보완 순서 — 제안

### 우선순위 1: 실제로 시작할 수 없는 방 방지

1. `roomCapacityLimit()`의 최대치만으로 버튼을 만들지 않고 **허용 인원 목록**을 둔다. 발로란트 경쟁전은 2·3·5명, 불멸 이상은 2·5명, 개인/2인 랭크는 2명이다. 자유랭크를 추가하면 2·3·5명이다. 1인은 게임에서 가능해도 서비스의 모집 방 목표 인원으로는 제외할 수 있다.
2. 방 생성뿐 아니라 참가·퇴장·강퇴·모드 변경·확정 시에도 전체 구성원을 재검사한다. 발로란트 5인으로 가능한 큰 티어 격차를 2~3인 출발에도 허용하는 오류를 막는다.
3. 방의 목표가 5명이고 현재 4명인 상태는 계속 모집할 수 있다. `4명으로 출발`할 때 해당 모드 규칙을 적용한다. 모집 마감과 게임 큐 진입 가능 여부도 별개 상태다.
4. 계정 자격·제재·MMR·배치 상태가 불명확하면 `확인 필요`로 남긴다. API 오류나 미연동을 최하위 티어·제약 없음으로 해석하지 않는다.

### 우선순위 2: 모드·랭크 정보 정리

- 롤의 `랭크`를 개인/2인 랭크와 자유랭크로 명확히 나눈다. 5명이 모인 방을 개인/2인 랭크로 표시할 수 없다.
- PUBG는 일반/경쟁전, 듀오/스쿼드, 플랫폼·지역·시점을 구분할 수 있어야 한다. 모든 필드를 화면에 동시에 늘어놓기보다 계정에서 정할 정보와 방에서 정할 정보를 나눈다.
- PUBG 티어·아이콘·더미 데이터·평균 계산에 크리스탈/서바이버와 4디비전을 반영해야 한다. 현재 `summary.ts`는 이전 6티어/5디비전 체계다.
- `내 티어` 하나만 저장하지 않는다. 롤 개인/2인과 자유랭크, 발로란트 PC와 콘솔의 기준을 구분한다. 시즌·확인 시각도 함께 관리한다.

### 우선순위 3: 사용자가 이해하는 제안

| 상황 | 제안할 안내 |
| --- | --- |
| 발로란트 4명 | `경쟁전은 한 명 더 필요해요` → 5번째 자리 모집 |
| 발로란트 2~3인 티어 초과 | `현재 인원으로는 티어 차이가 커요` → 5인 모집 또는 일반전 |
| 롤 한국 마스터 듀오 | `이 모드에서는 듀오가 제한돼요` → 자격을 만족하는 자유랭크 또는 일반전 |
| PUBG 플랫폼/시점 불일치 | 같은 환경의 방 추천. 설정 변경을 상대 동의 없이 적용하지 않음 |
| 발로란트 5인 RR 감소 | 참가 차단 대신 감소 조건 안내 |
| 비공개 MMR·공식 자료 불일치 | `게임에서 참가 가능 여부 확인이 필요해요` |

위 문구는 UX 제안이며 이번 변경에는 추가하지 않았다. 확인한 공식 규칙을 통과한 방을 대상으로 포지션·챔피언·음성 등 사용자가 원하는 조건을 비교하는 순서가 적절하다. 평균 승률·KDA로 게임 참가 자격을 대체하지 않는다.
