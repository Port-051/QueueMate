# 챔피언 초상화

Riot Games의 공식 Data Dragon 16.18.1 정사각형 초상화 PNG 원본이다.
모집 더미 데이터에 쓰는 10개 챔피언은 미리보기의 외부 요청을 줄이기 위해 포함한다.
전체 173개 챔피언의 한국어·영문 이름과 파일명은 `../../domain/championCatalog.ts`에 보관한다.
다른 챔피언은 같은 버전의 공식 CDN 이미지를 사용한다.

- [Data Dragon 문서](https://developer.riotgames.com/docs/lol#data-dragon)
- [한국 서버 버전](https://ddragon.leagueoflegends.com/realms/kr.json)
- [한국어 카탈로그](https://ddragon.leagueoflegends.com/cdn/16.18.1/data/ko_KR/champion.json)
- [영문 카탈로그](https://ddragon.leagueoflegends.com/cdn/16.18.1/data/en_US/champion.json)
- 이미지 경로: `https://ddragon.leagueoflegends.com/cdn/16.18.1/img/champion/{파일명}`

2026-09-14 원본 다운로드 및 버전 확인. 이미지는 수정하지 않았다.
League of Legends와 관련 자산의 권리는 Riot Games에 있다.
